## 5. Search-engine and recruiter-readability principles

- Put your full name and target role in the first Markdown heading.
- Put a concise, accurate summary in the first paragraph.
- Use natural phrases recruiters search for: `Full-Stack Developer`, `Software Engineer`, `React`, `Next.js`, `Node.js`, `Python`, `Machine Learning`, `Computer Vision`, and `Edge AI`.
- Give each featured project a distinct problem statement and a repository link.
- Add descriptive alt text to project images, diagrams and GIFs.
- Link to live demos and technical documentation where they exist.
- Keep project READMEs complete and current; profile SEO cannot compensate for weak individual repositories.
- Do not keyword-stuff, invent achievements, claim unverified proficiency, or add irrelevant topics.
- Update your profile after meaningful new projects, publications, internships, and awards.

## 6. Limits of GitHub README SEO

GitHub profile READMEs do not provide custom page title or meta-description tags. GitHub controls the rendered profile page. This package improves discoverability through a descriptive heading, natural keyword coverage, link structure, image alt text, repository metadata guidance, and consistent project documentation. It cannot guarantee Google ranking or indexing position.
