# External Visual Services & Notices

The README uses these independently operated services:

- Skill icons: https://skillicons.dev
- GitHub statistics, language cards and repository pins: https://github.com/anuraghazra/github-readme-stats
- Contribution streak: https://github.com/denvercoder1/github-readme-streak-stats
- GitHub activity graph: https://github.com/ashutosh00710/github-readme-activity-graph
- GitHub achievement trophy visualization: https://github.com/ryo-ma/github-profile-trophy
- Contribution snake generator: https://github.com/Platane/snk
- Extended GitHub metrics and achievement plugin: https://github.com/lowlighter/metrics

Third-party services can be rate-limited, cached, temporarily unavailable, or subject to changes in their terms and configuration. The local SVG banners and programmer GIF are included in this package.
